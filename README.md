## GitHub Search Dashboard (BitFlyer)

Simple GitHub repository search dashboard built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS** for BitFlyer.

It uses the [GitHub Search API](/https://docs.github.com/en/rest/reference/search) to search repositories and includes **pagination** for navigating through results.

## Prerequisites

- **Node**: version specified in `.nvmrc` (run `nvm use` if you use `nvm`)
- **npm** (bundled with Node)

## Scripts

- `npm run dev` – start the Vite development server.
- `npm run build` – create a production build.
- `npm run preview` – preview the production build locally.

## Getting Started

1. Log in using the demo credentials: **username**: `user`, **password**: `pass`.
2. After login, type any search keyword in the search input field.
3. Browse the list of matching repositories and use the pagination controls to move between pages of results.

## Notes

- This project uses the public GitHub Search API.
